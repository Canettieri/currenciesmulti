# Titan Currencies Multi

Titan Currencies Multi is a collection of Titan Panel plugins for tracking currencies, tokens, and currency-like items across multiple versions of World of Warcraft.

Titan Panel is required.

![Titan Currencies Multi menu](https://i.imgur.com/zNb4yaj.png)

![Currency plugins on the Titan bar](https://imgur.com/zzsLSp2.jpg)

## Features

- 172 currency and resource trackers on Retail, including Midnight, Housing, and older expansions.
- 28 trackers tailored to Mists of Pandaria Classic.
- Individual Titan plugins, so only the currencies you choose are displayed on the bar.
- Expansion and activity categories for easier navigation in the Titan menu.
- Character, realm, faction, and account-wide totals when supported by the currency or item.
- Session gains and losses, maximum and weekly-cap information, and configurable tooltip details.
- Direct access to the WoW currency window from supported plugins.
- A character-data management plugin for removing information saved for characters you no longer use.
- Automatic cleanup of saved data belonging to currencies and items removed from the addon.

## Supported game versions

| Game client | Included trackers | Main coverage |
| --- | ---: | --- |
| Retail / Midnight | 172 | Midnight, Housing, The War Within, Dragonflight, Shadowlands, and legacy content |
| Mists of Pandaria Classic | 28 | Mists of Pandaria, Cataclysm, Wrath of the Lich King, events, and general currencies |

Each game client loads only the plugins listed in its corresponding `.toc` file.

## How to use

1. Right-click the Titan Panel.
2. Open the **Information** category. Its name may differ depending on your game language.
3. Open an expansion or activity category and select the currencies you want to display.
4. Right-click an enabled currency plugin to configure its icon, label, balance, totals, and other available display options.

Most plugins update automatically when your currency or item quantity changes. Their tooltips can also show saved totals for other characters when that information is available.

## Languages

The addon currently includes translations for:

- English
- Brazilian Portuguese
- German
- Spanish (Spain)
- French
- Korean
- Russian

Unsupported locales fall back to English. Currency and item names are obtained directly from the WoW client whenever available.

## Missing a currency?

Please request it through the [GitHub issue tracker](https://github.com/Canettieri/currenciesmulti/issues). Include the currency or item name, the WoW game version, and a link or ID when possible.

## Support

Please report problems through the [GitHub issue tracker](https://github.com/Canettieri/currenciesmulti/issues). When reporting an issue, include the WoW game version, character locale, and any error message shown by the client.
